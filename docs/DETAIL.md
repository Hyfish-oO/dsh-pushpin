# 窗口置顶

会话头部右上角多一颗钉子，点一下把整个 DeepSeek Harness 窗口钉在其他窗口上面，再点一下取消。亮起表示已置顶。

## 功能

- 点击切换置顶。按钮显示的状态跟着 Windows 走：每次点击后都会回读窗口的 `WS_EX_TOPMOST` 标志位，不是按钮自己记的。
- 记住上次状态，DSH 重启后自动恢复（可在配置里关掉）。
- 常驻 PowerShell 进程按需启动，闲置超时后退出。
- 失败时按钮变红，悬停能看到原因，钉子旁边还会冒一个两秒的小气泡。

## 原理

DSH 没有把 Electron 的窗口对象开放给插件，所以插件走 Windows 原生接口：Host 侧保持一个常驻 `powershell.exe`，按行收发 JSON，通过 `user32.dll` 的 `SetWindowPos` / `GetWindowLong` 读写主窗口的置顶标志。

## 配置

配置文件 `%USERPROFILE%\.dsh\dsh-pin-window.json`，不存在时全部使用默认值：

- `idleTimeoutMs`：数字，默认 `120000`。常驻进程闲置多久后退出，`0` 表示不自动退出。
- `restoreOnStart`：布尔，默认 `true`。重启 DSH 后是否恢复上次的置顶状态。

配置在插件加载时读取，改完需要重启 DSH。

## 限制

- 独占全屏的程序（部分播放器、游戏）会盖住置顶窗口，这是系统机制，绕不过去。浏览器 F11 那种无边框全屏不受影响。
- 只钉一个窗口。钉的是点击那一刻在前台的那个 DSH 窗口，找不到时取第一个；其他 DSH 窗口不跟着置顶。
- 只在 Windows 上有效，其他平台上按钮不渲染。
- 系统策略或安全软件禁止运行 PowerShell 时，按钮会变红，悬停可以看到失败原因。
- 闲置后第一次点击要先起 PowerShell，会比平时慢几百毫秒。
